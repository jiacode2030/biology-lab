Translation & the genetic code

Ribosomes read the mRNA three bases at a time and string together amino acids in the order the codons specify.

The idea

The genetic code is read in codons of three bases. There are 64 codons: 61 code for amino acids and 3 are stop codons (UAA, UAG, UGA). AUG codes for methionine and is the start codon. The code is redundant (several codons for one amino acid) but unambiguous (each codon codes for only one), and it is nearly universal.

The ribosome (rRNA and protein) binds mRNA. Each tRNA carries one amino acid and has an anticodon complementary to a codon. At the start, a tRNA with methionine pairs with AUG in the P site. Then a tRNA enters the A site, a peptide bond forms, and the ribosome moves one codon (translocation). This repeats until a stop codon reaches the A site and release factors free the polypeptide.

Try this

Predict what will happen first. Then set it up and check.

  1. Go to the stage where the peptide bond forms. Which molecules join?

    What you should see

    The amino acid on the tRNA in the P site is joined to the one on the tRNA in the A site (the ribosome catalyzes it).

  2. Change the mRNA so the first AUG is missing. What happens?

    What you should see

    No start codon: translation does not begin (the tool reports no peptide).

Worked example

The mRNA 5′-AUGUUUGGCAAAUAG-3′ is translated. What is the polypeptide and how many amino acids does it have?

Try it yourself first, then reveal one step at a time.

  1. Codons. AUG | UUU | GGC | AAA | UAG.
  2. Amino acids. AUG = Met, UUU = Phe, GGC = Gly, AAA = Lys, UAG = stop.
  3. Answer. Met–Phe–Gly–Lys: 4 amino acids. Stop codons do not code for an amino acid.

Common mistakes

  • Counting the stop codon as an amino acid.
  • Starting to read at the first base instead of the first AUG.
  • Writing anticodons as identical to codons.
  • Saying the code is ambiguous (it is redundant, not ambiguous).
  • Mixing up tRNA (anticodon) with mRNA (codon).
